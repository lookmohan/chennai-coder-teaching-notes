# 👋 Welcome to Chennai Coder Teaching Notes

This repository contains the **class notes, code examples, practice programs, and learning materials** used during Chennai Coder programming classes.

## 🎯 Why are you here?

During our classes, we learn concepts by writing and practicing code.

Instead of keeping the class code only on one computer or searching through old messages, the materials are organized here so you can **access and revise them whenever you need.**

You can use this repository to:

* 📖 Review what was taught in class
* 💻 Refer to the code written during the sessions
* 🔁 Practice the programs again
* 🧠 Revise previous topics
* 📂 Access your class materials anytime
* 🚀 Continue practicing outside the classroom

## 📌 How should you use these materials?

When you want to revise a particular class:

**Python → Class-01**

or

**Python → Class-02**

and so on.

Open the files and go through the code that we covered during the class.

### 💡 Don't just copy the code.

Try to:

1. Read the code
2. Understand what each line does
3. Run the program yourself
4. Change the values
5. Experiment with the code
6. Try writing the program again without looking

**Programming is learned by practicing, not just by reading.**
